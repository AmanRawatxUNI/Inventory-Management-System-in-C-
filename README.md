# Inventory Management System in C++

A simple console-based Inventory Management System built in C++ that allows users to manage product categories, track inventory, and handle sales transactions. Designed using Object-Oriented Programming principles for modularity and future expansion.

## 🚀 Features

- Add and view **product categories**
- Add and view **products**
- Restock and sell products
- Maintain **sales/transaction records**
- Menu-driven interface using `do-while` and `switch-case`

## 🛠️ Technologies Used

- **C++**
- Object-Oriented Programming (OOP)
- Standard Template Library (STL)
- File-based storage (to be implemented)

## 🖥️ How It Works

The user interacts with a simple CLI (Command Line Interface) menu to:

1. Add new categories
2. Add products under categories
3. Display categories and product list
4. Restock or sell items
5. View all transaction history

### Sample Menu:
Inventory Management System
